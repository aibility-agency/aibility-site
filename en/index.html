    QUESTIONS

    Before we start.

    Do we need to change our software?

    Usually not. We start from the tools you already use; what’s possible depends on the available features and access.

    How long does it take?

    A first process is usually up and running in 2–4 weeks, depending on the integrations.

    Why a monthly fee?

    An automation works every day in an environment that keeps changing. The fee ensures it keeps running and improving, with a monthly report on what it delivered.

    How is data handled?

    Data stays on servers in Switzerland. We agree beforehand which data is needed and who can access it, in line with the Swiss Federal Act on Data Protection (FADP).
